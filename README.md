# sanvsexp

A VS Code extension project written in TypeScript.

## Run and debug

1. Install Node.js and npm if they are not already available.
2. Run `npm install` in this folder.
3. Press `F5` in VS Code to launch the Extension Development Host.
4. In the Extension Development Host, run **Hello World** from the Command Palette.

## Build

- `npm run compile` compiles the extension to `out/`.
- `npm run watch` recompiles when source files change.
